Development: VS Code (code editor), GitHub (version control).

Backend: Python  (language) + FastAPI (framework), PyPDF2 (doc parsing/PDF text extraction), HuggingFace Transformers (free models), Vertex AI free credits + Google Cloud Run (backend, free tier) / Node.js + Express.js + MongoDB Atlas + Mongoose 

Database/Hosting: Firebase free tier / Firestore (NoSQL database, free tier), Google Cloud Run free tier

AI/ML Google Cloud Vertex AI with Gemini Pro API (using Free Tier credits) + Python + LangChain

DevOps: GitHub Actions, GitHub Pages (for docs), Postman (free) / GitHub Actions + Docker + Google Cloud Run + Netlify
